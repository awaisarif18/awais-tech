# Awais Arif's portfolio

A Next.js portfolio with an experience timeline and four project case studies.

## Run locally

```sh
npm install
npm run dev
```

Open [localhost:3000](http://localhost:3000).

Project copy and destinations live in `app/content/projects.ts`. Experience, booking, and social links live in `app/content/profile.ts`. The original photographs are in `public/images`.

Run `npm run lint` and `npm run build` to check the project.
